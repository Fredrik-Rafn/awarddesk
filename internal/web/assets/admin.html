How these metrics are counted

Success rate = completed ÷ (completed + failed). A completed search with automatic recoveries counts as successful. Live success excludes cache hits. Cancelled, interrupted, running and queued jobs are shown separately and excluded from success-rate denominators. Median and P95 use completed live searches, including queue and retry time. Repeated or coalesced requests sharing a job count once. Separate manual retries are separate jobs; we do not infer that they are the same user journey. Statistics include only retained records in the selected window.
