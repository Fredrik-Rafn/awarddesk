Ongoing & recent searches

          

            Bounded workers queue searches when all accounts are busy. Identical
            ongoing queries share one job. Interrupted searches are recorded on
            restart.
          

          

        

        

          
Sticky proxies

          

            One authenticated Evomi endpoint per line. Each fresh login gets a
            new locked sticky ID; saved sessions keep their exact proxy. Changes
            apply to new leases. Removing a session’s endpoint requires that
            session to be prepared again.
          

          

          
          

            
          

        

        

          
Settings & API keys

          

            Saved immediately. EVA uses updates when an account next becomes
            idle. ANA and BA startup settings require a server restart. Empty
            secret fields keep their current value; use Clear to remove a key.
